Ports

A port is one capture card plus the device plugged into it (Android TV / Shield, Fire TV or Apple TV). Each port has its own picture and its own remote. Give each device a fixed address on your router.

Add port

Cards are told apart by the USB port they're plugged into.

New VLC link

A private link to the same stream (video + audio) for VLC or any player that opens network streams. In VLC: Media → Open Network Stream (Ctrl+N), paste the link, press Play. Anyone with the link can watch without signing in, so share it carefully. Revoking it stops playback within seconds.

Copy it now: for safety it can't be shown again (create a new one if you lose it).
